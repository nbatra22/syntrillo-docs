Pair New Devices

The procedure has the following steps:

  1. Click on the 'Generate a Temporary Pairing Code' button below. The code is simple, composed of two capitalized words with no space.
  2. On the Tenovi portal, edit the 'patient info' value for the device, paste this Temporary Pairing Code as 'External ID', and save your changes. Repeat for all new devices to pair.
  3. Click the 'Pair Device' button below. The system will replace the Tenovi External ID with the Healthie User ID, and add the Syntrillo code in a hidden device value/pair property.
  4. When pairing is completed, refresh the Tenovi portal to see the changes.
