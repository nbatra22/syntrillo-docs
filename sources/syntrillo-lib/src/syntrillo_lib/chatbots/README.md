# Chatbots - Operations Manual and Information

For now:
  - each different chatbot need to have its correspoding Healthie user (as a provider, with admin role)
  - chatbot providers are identified with a Heathie tag
  - the tag is used to identify the chatbot provider in the chatbot's configuration
  - this allows proper names to be displayed in the chat ie 'After Hours Support Chatbot'
