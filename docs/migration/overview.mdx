## Architecture: Before vs. After

<CardGroup cols={2}>
  <Card icon="server" title="Current System (Live)">
    **Frontend:** HTML/CSS rendered server-side via Flask templates

    **Backend:** Flask on PythonAnywhere — handles routing, rendering, and business logic in one process

    **Database:** AWS (MySQL via pymysql)

    **Auth:** Session-based, handled in Flask
  </Card>
  <Card icon="arrows-rotate" title="New System (In Progress)">
    **Frontend:** React 19 + TypeScript + Vite — runs in the browser, fetches data from the API

    **Backend:** FastAPI + Uvicorn — pure JSON API, no HTML rendering

    **Database:** Same AWS MySQL (shared `sources/syntrillo` layer)

    **Auth:** Token-based via `syntrillo_internal_key` query param, enforced per-endpoint
  </Card>
</CardGroup>

## Shared Business Logic

Both systems will the same logic layer located in `sources/syntrillo/`. This includes:

- `blood_pressure/` — BP analysis and grading (DB fetch and BP calculations)
- `stroke_risk_score_v2/` — stroke risk score computation (All DB fetches and Risk score calculation)
- `api_healthie/` — Healthie EHR integration
- `api_tenovi/` — Tenovi device integration
- `remote_monitoring/` — database manager
- `billing/`, `chatbots/`, `patient_onboarding/` — other modules //comment from Navya not entirely sure what all of these are

## Migration Plan

**Phase 1 — API layer (ongoing)** Port all Flask routes to FastAPI. Each old route becomes one or more focused REST endpoints that return JSON. No HTML is returned from the API. Auth is enforced via FastAPI dependency injection before any patient data is accessed.

**Phase 2 — Frontend (ongoing)** Build the React-TS frontend to consume the new API. The React app replaces all Jinja templates and Flask-rendered iframes. Components are organized by clinical domain (BP tab, risk score tab, etc.).

**Phase 3 — Deployment** Deploy FastAPI to AWS (replacing PythonAnywhere for the backend). The React app is served as a static build. The `apps/AWS` directory contains CDK infrastructure and Lambda functions for this phase.
