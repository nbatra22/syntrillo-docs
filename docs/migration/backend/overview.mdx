## Overview

The new backend is a FastAPI application located at `apps/FastAPI/`. It replaces the Flask server on PythonAnywhere and exposes a versioned JSON REST API under `/api/v1/`. No HTML is returned — all rendering is handled by the React frontend.

The server runs via Uvicorn and auto-generates interactive API docs at `/docs` (Swagger UI) and `/redoc`.

---

## Setup

**1. Install dependencies** (from `apps/FastAPI/`)

```bash
pip install -r requirements.txt
```

**2. Start the server**

```bash
uvicorn main:app --reload
```

The server starts at `http://127.0.0.1:8000`.

| URL                            | Purpose                  |
| ------------------------------ | ------------------------ |
| `http://127.0.0.1:8000/docs`   | Swagger UI (interactive) |
| `http://127.0.0.1:8000/redoc`  | ReDoc                    |
| `http://127.0.0.1:8000/health` | Health check             |

## App Structure

```text
apps/FastAPI/
├── main.py           # App factory, CORS middleware, router registration
├── config.py         # Settings loaded from .env
├── dependencies.py   # Shared FastAPI dependencies (auth, pseudonyms)
├── routes/
│   ├── blood_pressure.py   # /api/v1/blood-pressure/*
│   ├── risk_score.py       # /api/v1/risk-score/*
│   └── devices.py          # /api/v1/devices/*
├── schemas/
│   └── blood_pressure.py   # Pydantic response models
├── tests/
│   ├── unit/               # No HTTP, no network — pure logic tests
│   └── integration/        # HTTP layer with mocked dependencies
└── syntrillo -> ../../sources/syntrillo   # symlink
```
