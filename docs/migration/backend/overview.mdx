## Overview

The new backend is a FastAPI application located at `apps/FastAPI/`. It should replace the Flask server on PythonAnywhere.

The server runs via Uvicorn and also auto-generates API docs at `/docs` and `/redoc`.

## App Structure

```text
apps/FastAPI/
├── main.py           # App factory, CORS middleware, router registration
├── config.py         # Settings loaded from .env
├── dependencies.py   # Shared FastAPI dependencies (auth, pseudonyms)
├── routes/
│   ├── blood_pressure.py   # /api/v1/blood-pressure/*
│   ├── risk_score.py       # /api/v1/risk-score/*
│   └── devices.py          # /api/v1/devices/*
├── schemas/
│   └── blood_pressure.py   # Pydantic response models
├── tests/
│   ├── unit/               # No HTTP, no network — pure logic tests
│   └── integration/        # HTTP layer with mocked dependencies
└── syntrillo -> ../../sources/syntrillo   # symlink
```
