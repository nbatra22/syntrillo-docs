## What is SyntrilloClinic?

SyntrilloClinic is a clinical platform that provides healthcare providers with patient monitoring tools including blood pressure tracking, risk scoring, lab value management, and device integration.

## Current System

The platform is currently live and hosted on **PythonAnywhere**. The current stack consists of:

- **Frontend:** HTML/CSS served directly from PythonAnywhere
- **Backend:** Flask server handling all API logic and data processing
- **Database & Integrations:** AWS, configured via the `apps/AWS` directory

## System Migration (In Progress)

We are actively migrating the platform to a modern stack:

- **Frontend:** React + TypeScript (located in `apps/React-TS`)
- **Backend:** FastAPI (located in `apps/FastAPI`)

The goal of this migration is to improve scalability, maintainability, and developer experience. Both the current system and the new system are documented here.
